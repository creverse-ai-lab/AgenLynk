# AgenLynk `src/` 소유권 분류

이 목록은 0.4.0 파일 이동·삭제 전 기준선이다. `hybrid seam`은 그대로 유지할 목표 구조가 아니라, sidecar 추출 중 결합을 한 adapter로 모아야 하는 파일을 뜻한다.

Gateway 구현이 아니라 app packaging/install/activation 경계다. artifact 전환 후에도 역할을 검토해 유지하거나 Swift `GatewayRuntimeManager`로 옮긴다.

## Hybrid seam

현재 sidecar와 Gateway fork가 함께 의존한다. PR 1에서는 이 결합을 `sidecar/src/gateway/legacy-adapter.js`로 집중하고, pinned 1.4.0 전환 때 public client 또는 app-owned service로 교체한다.

```text
acp-registry.js
agent-catalog.js
config.js
gateway-settings.js
installer.js
providers.js
socket-rpc.js
version.js
```

## 이동 규칙

- sidecar는 `LegacyGatewayAdapter` 밖에서 Gateway fork/private path를 import하지 않는다.
- app runtime integration은 Gateway source tree hash를 새로 정의하지 않는다. release manifest와 lock digest를 검증한다.
- `gateway_config`, agent catalog, app runtime update는 1.4.0 Gateway public wire라고 가정하지 않는다.
- `macos/scripts/build-app.sh`는 sidecar를 Gateway seed 안에 복사하지 않는다.
- 파일 삭제는 public client + pinned artifact + package smoke가 통과한 뒤에만 한다.
